# nba-shot-probability-xgboost
NBA Shot Prediction Model (XGBoost)
An end-to-end machine learning pipeline built in R to estimate the probability of shot success (make_prob) for NBA field goal attempts. Developed as part of the OKC Thunder Analyst Intern technical project, this repository contains the complete modeling pipeline, feature engineering logic, model evaluation, and final test set predictions.

Performance Summary:
-Model Architecture: Extreme Gradient Boosting (xgboost)
-Validation Score: 0.62922 Log-Loss (evaluated via an 80/20 stratified train/validation split)
-Key Metric Focus: Calibrated probability outputs optimizing for binary log-loss rather than hard classification thresholding.

Project Deliverables:
This repository includes all core submission assets:
-project_code.R: Complete R modeling pipeline containing data pre-processing, spatial feature extraction, hyperparameter tuning, model training, cross-validation, and inference logic.
-submission.csv: Final test set predictions with populated make_prob values generated by the trained XGBoost model.
-project_writeup.pdf: A comprehensive 4-page technical narrative detailing feature engineering choices, validation strategy, model selection, trade-off analyses, and practical basketball application.

Key Engineered Features:
To capture non-linear shooting difficulty and spatial-temporal defender mechanics, the pipeline generates several specialized features:
1. Spatial Geometry:
-dist_to_rim: Euclidean distance from shot location to the hoop.
-dist_to_rim_sq: Non-linear distance transformation accounting for accuracy decay over
-distance.is_corner_three: Binary flag identifying high-value corner three-point attempts based on court coordinates.

2. Defensive Contests & Mechanics:
-def_pressure_ratio: Contesting defender distance relative to shot distance (closest_def_dist / dist_to_rim).
-is_moving_jumper: Indicator capturing player movement during pull-up jumpers versus catch-and-shoot attempts.
-is_late_clock: Indicator for late-shot-clock situations ($\le 4$ seconds remaining) forcing low-quality bailout attempts.
